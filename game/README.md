# 🚀 نيزك — لعبة ويب جاهزة للرفع على ProFreeHost

لعبة عربية كاملة تعمل بالمتصفح (جوال + حاسوب)، مكتوبة بـ HTML/CSS/JavaScript خالص
مع خلفية PHP بسيطة للوحة الأبطال. لا تحتاج أي تثبيت أو أدوات بناء — ارفع الملفات وشغّل.

---

## 1) ماذا يوجد داخل المجلد؟

```
game/
├── index.html          صفحة اللعبة
├── privacy.html        سياسة الخصوصية (تشترطها الشبكات الإعلانية)
├── ads.txt             ملف تفويض المعلنين
├── robots.txt
├── .htaccess           إعدادات Apache
├── assets/
│   ├── css/style.css
│   └── js/
│       ├── game.js     محرّك اللعبة
│       ├── ads.js      ⬅️ هنا تضع أكواد إعلاناتك
│       └── api.js      الاتصال بلوحة الأبطال
├── api/
│   ├── config.php      ⬅️ هنا تضع بيانات قاعدة البيانات
│   ├── lib.php
│   ├── session.php     يصدر تذكرة الجولة
│   ├── submit.php      يستقبل النتيجة ويتحقق منها
│   └── top.php         أفضل 20 نتيجة
└── data/               بيانات وقت التشغيل (يُنشأ تلقائياً)
```

**مزايا اللعبة:** تحكّم باللمس والفأرة والأسهم • نيازك بصعوبة متصاعدة • عملات
قابلة للجمع • ثلاث قوى (درع 🛡 / مغناطيس 🧲 / إبطاء ⏳) • متجر بخمس مركبات •
لوحة أبطال أونلاين • مشاركة النتيجة • إيقاف مؤقت • تعمل حتى لو تعطّل الخادم.

## 2) الرفع على ProFreeHost — خطوة بخطوة

1. سجّل في ProFreeHost وأنشئ حساب استضافة، وستحصل على نطاق فرعي مجاني.
2. ادخل **Control Panel → File Manager** (أو استخدم FTP ببرنامج FileZilla).
3. افتح مجلد **`htdocs`** (وأحياناً يُسمّى `public_html`).
4. ارفع **محتويات** مجلد `game/` كلها داخل `htdocs` مباشرة
   — أي أن `index.html` يجب أن يكون في `htdocs/index.html` وليس `htdocs/game/index.html`.
5. افتح نطاقك في المتصفح. اللعبة تعمل الآن ✅

> ⏳ نطاقات ProFreeHost الجديدة تحتاج أحياناً من 15 دقيقة إلى ساعتين حتى تعمل.

### تفعيل لوحة الأبطال (اختياري لكنه مهم للاحتفاظ باللاعبين)

اللوحة تعمل فوراً بدون قاعدة بيانات (تُخزَّن في ملفات JSON داخل `data/`).
لكن الأفضل استخدام MySQL:

1. **Control Panel → MySQL Databases** → أنشئ قاعدة بيانات ومستخدماً.
2. افتح `api/config.php` وعبّئ:
   ```php
   'db_host' => 'sqlXXX.profreehost.com',   // العنوان الذي تعطيك إياه اللوحة
   'db_name' => 'xxxxxxx_nayzak',
   'db_user' => 'xxxxxxx_nayzak',
   'db_pass' => 'كلمة المرور',
   ```
3. الجداول تُنشأ تلقائياً عند أول زيارة. لا تحتاج phpMyAdmin.

**تأكد أن مجلد `data/` قابل للكتابة** (صلاحية 755 أو 777 من File Manager)،
فهو يخزّن المفتاح السري وحدود الإرسال.

### إن لم تعمل لوحة الأبطال
افتح `نطاقك/api/top.php` في المتصفح. المفروض يظهر `{"ok":true,"rows":[]}`.
إن ظهر خطأ 500 فغالباً `data/` غير قابل للكتابة، أو بيانات قاعدة البيانات خاطئة.

## 3) 💰 الربح من اللعبة — الحقيقة كاملة

### الخلاصة أولاً
**نعم، يمكن الربح — لكن الدخل يأتي من الزوار لا من اللعبة.**
لعبة ممتازة بلا زوار = **صفر ريال**. اللعبة جاهزة تقنياً بالكامل للإعلانات،
والجزء الصعب المتبقي عليك هو جلب اللاعبين.

### ⚠️ أمور يجب أن تعرفها قبل أن تبدأ

| العقبة | التفصيل |
|---|---|
| **Google AdSense** | يرفض عملياً النطاقات الفرعية المجانية. للتقديم عليه تحتاج نطاقاً خاصاً (`.com` بنحو 40–50 ريالاً سنوياً) ومحتوى وزيارات حقيقية. |
| **شروط ProFreeHost** | الاستضافات المجانية تضع قيوداً على الإعلانات وقد تحقن إعلاناتها الخاصة، وقد توقف الحساب عند ارتفاع الزيارات. اقرأ شروط الخدمة قبل وضع أي إعلان. |
| **الاستضافة المجانية بطيئة** | عند نجاح اللعبة ستحتاج استضافة مدفوعة (≈ 10–20 ريالاً شهرياً) أو استضافة مجانية أسرع مثل Cloudflare Pages للملفات الثابتة. |
| **حد السحب** | كل شبكة لها حد أدنى للسحب (غالباً 5–100 دولار). قبل بلوغه لا تستلم شيئاً. |

### الطريق العملي الموصى به

**المرحلة 1 — ابدأ الآن مجاناً:**
اشترك في شبكة تقبل النطاقات المجانية عادةً وتناسب الألعاب:
- **Monetag** أو **Adsterra** — الأسهل قبولاً والأنسب للألعاب (تدعم إعلان المكافأة).
- بدائل: HilltopAds، PropellerAds، Galaksion.

**المرحلة 2 — بعد وصولك ~200 زائر يومياً:**
اشترِ نطاقاً خاصاً وانقل اللعبة إليه، ثم قدّم على AdSense (عوائده أعلى وأنظف).

### كيف تضع كود الإعلان؟ (كل شيء في ملف واحد)

افتح `assets/js/ads.js` وعدّل كائن `CONFIG` فقط:

```js
banner: {
  enabled: true,
  html: '<هنا تلصق كود البانر الذي أعطتك إياه الشبكة>'
},

interstitial: {          // إعلان بين الجولات
  enabled: true,
  zoneId: '1234567',     // رقم الزون من Monetag/Adsterra
  everyNGames: 3,        // كل 3 جولات
  minSecondsBetween: 90
},

rewarded: {              // إعلان "شاهد وأكمل اللعب" — الأعلى ربحاً
  enabled: true,
  zoneId: '7654321',
  minSecondsBetween: 45
}
```

- إن أعطتك الشبكة **سكربت SDK** (مثل Monetag): ضع السكربت في `<head>` داخل
  `index.html`، وضع رقم الزون في `zoneId`. الكود يستدعي `show_<zoneId>()` تلقائياً.
- إن أعطتك **Direct Link** فقط: ضعه في `directLink` بدل `zoneId`.
- إن تركت كل شيء `enabled: false` تعمل اللعبة بلا إعلانات إطلاقاً.

ثم عدّل `ads.txt` بالأسطر التي تعطيك إياها الشبكة، وأضف اسم الشبكة وبريدك
في `privacy.html` — أكثر الشبكات تشترط ذلك للموافقة على موقعك.

### كم المتوقع فعلياً؟

أرقام تقريبية لزيارات عربية (تختلف كثيراً حسب الدولة ونوع الإعلان):

| الزوار يومياً | الدخل الشهري التقريبي |
|---|---|
| 100 | أقل من 3 دولارات |
| 1,000 | 15 – 60 دولاراً |
| 10,000 | 150 – 600 دولار |

إعلان المكافأة (زر «شاهد إعلاناً وأكمل») هو الأعلى عائداً لأن اللاعب يشاهده
بإرادته — لذلك بُني في اللعبة من البداية.

### مصادر دخل أخرى مبنية في اللعبة أصلاً
- **المتجر**: يعمل حالياً بالعملات المجانية. يمكن لاحقاً ربطه بدفع حقيقي
  (مثل PayPal أو تحويل بنكي) لبيع المركبات أو إزالة الإعلانات.
- **الرعاية**: عند وجود زيارات ثابتة يمكن بيع مساحة البانر مباشرة لمعلن عربي
  بسعر شهري ثابت — عادةً أفضل من الشبكات.

### من أين تأتي بالزوار؟ (الجزء الأهم)
- تيك توك وريلز: مقاطع 15 ثانية لأفضل جولاتك مع «هل تتخطى رقمي؟».
- تحدّي لوحة الأبطال في مجموعات واتساب/تيليجرام — اللوحة موجودة لهذا السبب.
- مجتمعات الألعاب العربية على X وديسكورد.
- انشر اللعبة في مواقع تجميع ألعاب HTML5 (itch.io مجاني).

## 4) التطوير محلياً

```bash
cd game
php -S localhost:8000     # ثم افتح http://localhost:8000
```
تعمل اللعبة أيضاً بفتح `index.html` مباشرة، لكن لوحة الأبطال ستكون محلية فقط.

## 5) ملاحظات أمنية

لوحة الأبطال محميّة بـ: تذكرة موقّعة لكل جولة (HMAC) + رفض النتائج غير
المنطقية زمنياً + منع إعادة استخدام التذكرة + حد إرسال لكل IP + تنظيف الأسماء
من HTML. هذا يرفع تكلفة الغش كثيراً، لكن **أي لعبة تعمل داخل المتصفح
قابلة للتلاعب نظرياً** — لا تربط جوائز مالية حقيقية بالنتائج مباشرة.
